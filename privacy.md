# Privacy Policy for In The Loop Chrome Extension

## 1. Data Collection and Storage

In The Loop collects and stores the following user data locally on the user's device:

- School subdomain (e.g., "lynbrook", "montavista")
- School Loop username and password (if entered by the user)
- Overall grade percentages for each class
- Theme selection and customization options

## 2. Purpose of Data Collection

This data is collected and used solely to provide the extension's core functionality:

- Automatic login to School Loop
- Grade calculation and analysis
- Custom theme application
- Grade change notifications

## 3. Data Storage and Security

- All user data is stored locally on the user's device using Chrome's storage API. 
- No data is transmitted to or stored on external servers.
- The username and password, if entered by the user, are encrypted before being stored locally.

## 4. Data Collection Process

- All data is collected only if the user voluntarily allows and enters it.
- The extension does not automatically collect or store any data without user consent.

## 5. Data Sharing

In The Loop does not share any user data with third parties. All data remains on the user's device.

## 6. Data Access and Control

Users can view, modify, and delete their stored data at any time through the extension's options page.

## 7. Updates to Privacy Policy

This privacy policy may be updated occasionally. Users will be notified of any significant changes.
